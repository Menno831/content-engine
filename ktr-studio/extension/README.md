# KTR DM Runner — installatie (eenmalig, 1 minuut)

1. Open Chrome en ga naar `chrome://extensions`
2. Zet rechtsboven **Ontwikkelaarsmodus** aan
3. Klik **Uitgepakt laden** (Load unpacked)
4. Kies deze map: `~/content-engine/ktr-studio/extension`
5. Klaar. Open het platform → Outreach → DM-sprint → knop **⚡ Run 10**

Wat hij doet: opent max 10 DM-chats in tabs (3 sec ertussen) en typt het
klaargezette bericht alvast in. Jij loopt de tabs langs en drukt alleen op
versturen. De extensie verstuurt zelf nooit iets.
